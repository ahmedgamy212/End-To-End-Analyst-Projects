# End-to-End E-commerce Analytics Pipeline

## Project Overview
This project demonstrates a complete E-commerce analytics workflow using Python, SQL, and Power BI.  
The goal was to clean, transform, analyze, and visualize E-commerce sales data to generate business insights and KPIs.

---

## Tools & Technologies
- Python (Pandas, NumPy)
- SQL
- Power BI
- CSV Dataset

---

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Removed duplicates
- Handled missing values
- Standardized column formats
- Prepared data for analysis

### 2. Exploratory Data Analysis (EDA)
- Revenue analysis
- Monthly sales trends
- Customer behavior analysis
- Product performance tracking

### 3. SQL Analysis
Performed analytical queries such as:
- Revenue calculations
- Sales trends
- Customer insights
- KPI generation

### 4. Dashboard Creation
Built an interactive Power BI dashboard including:
- Revenue KPIs
- Sales trends
- Customer metrics
- Product insights

---

## Dataset
The dataset used in this project contains E-commerce transaction data including:
- Orders
- Customers
- Products
- Revenue
- Sales dates

---

## Key Insights
- Identified top-performing products
- Analyzed monthly revenue growth
- Tracked customer purchasing behavior
- Generated business KPIs for decision-making

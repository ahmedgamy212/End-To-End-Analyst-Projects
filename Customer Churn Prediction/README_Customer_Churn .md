# Customer Churn Prediction

## Project Overview
This project focuses on predicting customer churn using data analysis and machine learning techniques.  
The objective is to identify customers likely to leave and understand the factors affecting churn behavior.

---

## Tools & Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn
- CSV Dataset

---

## Project Workflow

### 1. Data Cleaning
- Removed inconsistencies
- Handled missing values
- Encoded categorical variables
- Prepared features for modeling

### 2. Exploratory Data Analysis (EDA)
- Customer distribution analysis
- Churn rate analysis
- Correlation analysis
- Feature importance exploration

### 3. Model Building
Applied machine learning models for churn prediction:
- Logistic Regression
- Classification workflows
- Model evaluation techniques

### 4. Evaluation
Used performance metrics such as:
- Accuracy
- Precision
- Recall
- Confusion Matrix

---

## Dataset
The dataset contains customer information such as:
- Demographics
- Subscription details
- Customer activity
- Churn status

---

## Project Goals
- Predict customer churn
- Discover factors affecting customer retention
- Support business decision-making
